The seven statements

Stated once, in full, here. No section repeats them.

  1. 01Research use onlyThis build exists for methods research. It is not a medical device and is not cleared for care.
  2. 02Retrospective, not liveEvery case is a recorded stay replayed from a fixed dataset. Nothing here is live monitoring.
  3. 03No diagnosisLabels shown in a case come from the source data. The system produces none of its own.
  4. 04No causal or counterfactual claimForecasts describe an observed trajectory. They do not state what an intervention would have done.
  5. 05No treatment recommendationThe Rx view demonstrates a rule set against public labels. It does not recommend care for a real patient.
  6. 06No automated prescribingNo output of this system can be sent to an order entry system. There is no prescribing action in the product.
  7. 07A forecast cannot change a drug rankingThe Rx engine and the forecast model are isolated. Neither reads the other's output.
